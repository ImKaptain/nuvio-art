# Nuvio Collection Cards Suite

This directory contains wide **1640 × 720 px** showcase header cards designed specifically for the Nuvio Collections portal and community collection pages.

> [!NOTE]
> These cards are high-level collection row banners and are **completely distinct** from the individual folder cover artwork found in `/art/`.

## Card Specifications
- **Dimensions**: `1640 × 720 px` (High-DPI 2.27:1 widescreen ratio)
- **Format**: Lossless 24-bit PNG
- **Typography**: Inter & Montserrat ExtraBold
- **Composition**: Multi-sphere mesh prism glow, film perforations, live stat badges, sales pitch value propositions, and trademark-safe blurred showcases for networks/streaming/studios.
